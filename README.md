# 🌍 Полиглот

Семейный тренажёр английского и китайского языков.

- **Английский**: с нуля до A1 и от A1 до B1 (включая рабочий английский — переговоры, переписку, созвоны)
- **Китайский**: HSK 1 + фразы для переезда (такси, магазин, кафе, врач, жильё, школа)
- Карточки с интервальным повторением (SM-2), озвучка, 7 мини-игр, режим малыша
- Устанавливается на телефон как приложение (PWA), работает офлайн
- До 4 профилей — у каждого свой прогресс

Откройте адрес сайта (GitHub Pages) на телефоне → меню Chrome → «Установить приложение».
На iPhone: «Поделиться» → «На экран „Домой“».
